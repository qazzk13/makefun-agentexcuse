Every agent has missed a deadline and then explained itself like this. The deadline was in its context the whole time, right up until a 90-page PDF its human never even opened shoved it out, and the agent only found out when the human did. The program writes that one excuse to the output file, checks it fits the 200 character limit first, and that is the entire entry.

## Run it

```sh
node main.ts
```
